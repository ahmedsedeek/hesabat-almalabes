# دليل التطوير

## البيئة

```bash
node -v        # 20 أو أحدث
npm install    # يُرجم better-sqlite3 لبيئة Electron تلقائيًا
npm run dev
```

### الوحدة الأصلية (better-sqlite3)

مرتبطة بـ ABI ومعمارية محدَّدين. `scripts/use-abi.mjs` يبدّل بين النسختين
ويحتفظ بهما في `.native-cache`:

```bash
npm run abi:node       # للاختبارات (يُستدعى تلقائيًا قبل npm test)
npm run abi:electron   # للتشغيل والبناء (يُستدعى تلقائيًا قبل dev/build)
```

> إذا ظهر خطأ `incompatible architecture` بعد توليد مثبّت لمعمارية أخرى،
> شغّل `npm run abi:electron` لاستعادة النسخة الصحيحة.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل مع إعادة التحميل الفوري |
| `npm test` | كل الاختبارات (٧٧ اختبارًا) |
| `npm run typecheck` | فحص الأنواع للنواة والواجهة |
| `npm run build` | فحص الأنواع + بناء الحزمة |
| `npm run selftest` | فحص ذاتي شامل داخل Electron |
| `npm run dist:mac` / `dist:win` | توليد المثبّتات |

### توليد المثبّتات

| الهدف | أين يُبنى |
|---|---|
| **macOS** (`.dmg` + `.zip` لمعماريتي arm64 و x64) | على جهاز ماك |
| **Windows** (`.exe`) | على جهاز ويندوز — أو عبر `.github/workflows/release.yml` |

> مثبّت ويندوز **لا يمكن توليده من ماك بمعالج Apple Silicon**: الأداة التي تضبط
> أيقونة وبيانات الملف التنفيذي تعمل عبر Wine المتوفّر لمعالجات Intel فقط.
> الحل الجاهز: ادفع وسم `v1.0.0` فيبني GitHub Actions المثبّتَين معًا،
> أو شغّل `npm run dist:win` على جهاز ويندوز مباشرة.

> بعد توليد مثبّت لمعمارية مختلفة قد تُستبدل الوحدة الأصلية؛
> شغّل `npm run abi:electron` قبل العودة إلى التطوير.

## إضافة ميزة جديدة — الترتيب الإلزامي

1. **المخطط** — هجرة جديدة في `src/main/db/migrations/` برقم أعلى.
2. **القاعدة المحاسبية** — وثّقها في `docs/ACCOUNTING.md` قبل كتابة الشيفرة.
3. **الخدمة** — في `src/main/services/`، وكل العملية داخل معاملة واحدة.
4. **الاختبار** — تحقّق من الأرقام: الأرصدة، المخزون، توازن ميزان المراجعة.
5. **مسار IPC** — في `src/main/ipc/` مع تحديد الصلاحية المطلوبة.
6. **الواجهة** — في `src/renderer/src/pages/` أخيرًا.

## قواعد غير قابلة للتفاوض

| القاعدة | السبب |
|---|---|
| لا منطق مالي في الواجهة | الواجهة تعرض فقط؛ النواة تحسب |
| لا `float` للمال | استخدم دوال `@shared/money` |
| لا `toISOString()` للتواريخ | استخدم `@shared/date` تفاديًا لانزياح اليوم |
| لا حذف لسجل مالي | الإلغاء بقيد عكسي + سبب في سجل المراجعة |
| كل عملية في معاملة واحدة | إما أن تنجح كل الخطوات أو لا شيء |
| كل رسالة خطأ بالعربية | `AppError` فقط؛ التفاصيل التقنية في السجل |
| كل عملية مؤثرة تُسجَّل | `AuditService.log` مع السبب |

## الاختبارات

| الملف | التغطية |
|---|---|
| `foundation.test.ts` | المخطط، حسابات المبالغ، الترقيم، القيد المزدوج |
| `sales.test.ts` | البيع، المخزون، التكلفة، المردودات، كشف الحساب |
| `purchase-production.test.ts` | الشراء، توزيع الشحن، دورة التصنيع الكاملة |
| `accounting.test.ts` | الأرباح، الميزانية، ميزان المراجعة، التسويات، الصلاحيات |
| `backup-import.test.ts` | التشفير، النسخ والاستعادة، الاستيراد، التصدير |
| `performance.test.ts` | ١٠٠٬٠٠٠ فاتورة مع قياس زمن كل شاشة |

**الفحص الذاتي** (`npm run selftest`) يعمل داخل Electron الحقيقي ويغطي ما لا تغطيه
اختبارات Node: طبقة IPC، فحص الصلاحيات، توليد PDF العربي، وتصدير Excel.

## إضافة لغة إنجليزية لاحقًا

البنية جاهزة: `locale.language` في الإعدادات، و`name_en` في شجرة الحسابات.
الخطوات: استخراج النصوص إلى ملف موارد، إضافة `t()` في الواجهة والقوالب،
وتبديل `dir` بين `rtl` و`ltr` على عنصر `html`.
